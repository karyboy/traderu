# TradeNetAI

This project is a custom AI-powered trading platform that recognizes your unique candlestick setups and provides real-time alerts. Built with React, Vite, and Tailwind CSS, and designed for deployment on Netlify.

## 🚀 Local Development (Netlify)

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [npm](https://www.npmjs.com/)
- [Netlify CLI](https://docs.netlify.com/cli/get-started/) (`npm install -g netlify-cli`)

### 1. Clone the Repository
```sh
git clone <your-repo-url>
cd traderu-1
```

### 2. Install Dependencies
```sh
npm install
```

### 3. Build the Project
```sh
npm run build
```

### 4. Run Locally with Netlify
```sh
netlify dev
```
This will start a local server (usually at http://localhost:5173) that simulates the Netlify production environment, including redirects and serverless functions.

### 5. Open in Browser
Go to http://localhost:5173 or the URL shown in your terminal.
